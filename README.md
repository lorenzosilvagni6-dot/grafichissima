# Grafichissima — Prototype V2

Luxury static website prototype for regenerated leather hospitality accessories.

## Included
- Luxury editorial homepage
- Photographic hero section with real-looking product imagery
- 6 product families with premium product cards
- Conditional configurator by product type
- Menu sizes: A4, 23×23 cm, A5
- Placemat shapes: rectangular, round, oval, pentagon, hexagon, drop, custom
- Custom dimensions
- UV print / blind deboss / embossing choices
- Embossing texture selector
- Color swatches
- Quantity selector and indicative dynamic estimate
- Editorial social / inspiration section
- Responsive mobile layout
- Ready for GitHub Pages

## Notes
The placeholder 2D graphics have been replaced with embedded photographic visuals to better present the product line and luxury positioning of the brand.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages
This is a static project and can be deployed directly through GitHub Pages without a build step.
